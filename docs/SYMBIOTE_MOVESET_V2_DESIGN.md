# Symbiote moveset v2 (v0.17.5) — APPROVED 2026-11-19, BUILT 2026-11-19 (numbers, tap/hold rules and tests: `SYMBIOTE_REFERENCE.md` "Moveset v2")

User: "Can we come up with a better moveset for symbiote please, the power needs more attacking moves while not losing what i
can already do". Approved as shown ("Yes, build it"). Applies to the Normal-host Symbiote kit (Lethal Protector suit). Black
Suit Spider-Man and Agent Venom keep their own kits.

How it adds attacks without losing anything: the Blade and Thorns toggles merge into one Form cycle on V (freeing C), and hold
variants are added on R, G, Z and C.

| Key | Move | Status |
|---|---|---|
| R | Tendril Strike; every 3rd strike in a row becomes a **Tendril Slam** (yanks the target in and smashes it down) | kept + new finisher |
| Shift+R | Tendril Sweep | kept |
| Hold R | **Impaling Spear**: charge a thick tendril spear, release to pierce everything in a 10-block line and pin the first target 1 s | new |
| G | Spike Shot | kept |
| Shift+G | Spike Fan | kept |
| Hold G | **Spike Rain**: spikes launched up rain on a target area for 3 s | new |
| X | Symbiote Lunge; in the air: **Dive Bomb** straight down into a slam | kept + new air version |
| Shift+X | Grapple | kept |
| Z | Tendril Barrage (Blade Slash in Blade form) | kept |
| Shift+hold Z | Onslaught | kept |
| Hold Z | **Ground Eruption**: tendrils burst from the ground in a line ahead, launching mobs up | new |
| C | **Maw Bite**: short lunge + bite with the animated jaw, big damage, heals some Biomass | new |
| Hold C | **Devour**: grab an enemy under 25% health and eat it (execute, big Biomass heal, tongue animation) | new |
| Shift+C | Tendril Grab (C again throws) | kept |
| V | **Form**: cycles Normal → Blade → Thorns (one button instead of two toggles) | merged |
| Shift+V | Symbiote Shield | kept |

Also: with the suit on, normal punches get +1 block reach and every 3rd punch in a row knocks back. Unchanged: Onslaught, Let It
Take Over / Frenzy, the Biomass bar, existing cooldowns; the Lethal Protector mouth snarls on the new attacks and Devour plays
the tongue. Tap vs hold: a tap fires on release under ~8 ticks, a hold starts at ~8 ticks (no double firing). Hold-C Devour on a
target that is not below 25% falls back to Maw Bite. Bosses can't be Devoured (they take a heavy bite instead).
